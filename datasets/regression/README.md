# Regression datasets

Public datasets suitable for regression practice. CSV snapshots are included in this folder; the table below links to their public sources for provenance. Check source terms before use.

| Dataset | Example target | Source |
| --- | --- | --- |
| Boston Housing | `medv` (median home value) | [CSV source](https://raw.githubusercontent.com/selva86/datasets/master/BostonHousing.csv) |
| Auto MPG | `mpg` | [CSV source](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/mpg.csv) |
| Tips | `tip` | [CSV source](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/tips.csv) |

The datasets have different schemas and may include missing values or categorical columns. Review and preprocess them for the selected modeling workflow.
