# Classification datasets

Public datasets commonly used for classification experiments. These files are linked at their original sources; download the source data as part of your workflow or place a reviewed copy in this folder if your use case requires a local snapshot.

| Dataset | Typical target | Source |
| --- | --- | --- |
| Wisconsin Breast Cancer Diagnostic (WBCD) | Diagnosis / class | [CSV source](https://raw.githubusercontent.com/selva86/datasets/master/BreastCancer.csv) |
| Wine recognition | Wine cultivar/class (first column in the UCI data) | [UCI Wine data](https://archive.ics.uci.edu/ml/machine-learning-databases/wine/wine.data) · [UCI dataset page](https://archive.ics.uci.edu/dataset/109/wine) |
| Iris | Species | [CSV source](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv) |

**Note:** The UCI Wine file is headerless. Refer to the UCI dataset documentation for its attribute names and intended use.
