# BMC Integrator training datasets

A small collection of public datasets for experimenting with model training workflows orchestrated by **BMC Integrator**. Datasets are organized by the common supervised-learning task they can support.

## Dataset collections

- [Classification](datasets/classification/README.md): WBCD (Wisconsin Breast Cancer Diagnostic), Wine, and Iris.
- [Regression](datasets/regression/README.md): Boston Housing, Auto MPG, and Tips.

## Using the datasets

The collection pages link to the original public sources. Check each source's license and terms, and review its schema, target column, missing values, and any preprocessing requirements before using it. In particular, some sources are hosted in repositories with licenses or terms that may differ from this repository.

This repository is a dataset collection for model-training workflows; it does not contain model code or workflow definitions.
